# نظام أتمتة السوشيال ميديا — المرحلة ١

منتج بايثون **متعدّد العلامات** يدير صفحات فيسبوك وإنستغرام، يحلّل الصور والأوصاف بالذكاء الاصطناعي،
يولّد **بنك محتوى** كبيرًا، ويجدول النشر بكمّيات يومية محددة. مهيّأ مسبقًا لعلامتَي **بيج رايش (ديكور)**
و**إنكيدو (مدارس)**.

> **وضع التشغيل الافتراضي = تجريبي (Mock):** يعمل النظام بالكامل **دون أي مفتاح مدفوع** — يولّد نصوصًا
> وصورًا نائبة وينشر نشرًا وهميًا، لتجرّب المنظومة كاملة بأمان. عند الجاهزية بدّل `APP_MODE=live` واملأ المفاتيح.

---

## التشغيل على ويندوز (إلى مجلدك `E:\...\ادارة بيجيات`)

1. **نزّل هذا المجلد** (`social_automation`) من المستودع إلى جهازك، مثلًا إلى:
   `E:\New folder\تطبيقات\ادارة انكيدو\ادارة بيجيات`
   - عبر GitHub Desktop، أو `git clone`، أو زر **Download ZIP** ثم فكّ الضغط.
2. ثبّت **Python 3.11+** من [python.org](https://www.python.org/downloads/) (فعّل خيار *Add to PATH*).
3. **انقر مرّتين على `run.bat`** — سيُنشئ البيئة، يثبّت المتطلبات، ويشغّل الخادم.
4. افتح المتصفح على **<http://127.0.0.1:8000>** — لوحة التحكم.

> إن أردت تشغيله يدويًا:
> ```bat
> python -m venv .venv
> .venv\Scripts\activate
> pip install -r requirements.txt
> copy .env.example .env
> uvicorn app.main:app
> ```

## كيف تستخدمه (لوحة التحكم الكاملة)

1. **الإعدادات والمفاتيح:** اضغط على شارة الوضع أعلى اليمين (تجريبي/مباشر) لتضبط وضع التشغيل وتضيف مفاتيح الذكاء الاصطناعي — كل ذلك من المتصفح دون لمس أي ملف.
2. اختر العلامة (بيج رايش / إنكيدو) من التبويبات.
3. **أضف محتوى:** اكتب وصفًا و**ارفع صورة** (أو ضع رابطًا) → اضغط «حلّل وولّد المحتوى».
4. **راجع بنك المحتوى:** عدّل نص أي منشور أو احذفه قبل الجدولة.
5. اضغط **خطّط اليوم** → يجدول الكمّيات اليومية في أوقاتها، وتظهر في «المنشورات المجدولة».
6. **إعدادات العلامة:** عدّل النبرة والهاشتاغ والأوقات والكمّيات و**حسابات Meta** (معرّف الصفحة/إنستغرام والتوكِن) — تُحفظ فورًا.
7. المجدوِل ينشر تلقائيًا في المواعيد. زر **نشر فوري** للاختبار.

> 🔒 القيم السرية (التوكِن والمفاتيح) لا تُعرض بعد حفظها — تظهر «محفوظ» فقط، ولا تُمسح عند إعادة الحفظ.

## الانتقال إلى النشر الحقيقي (live)

1. جهّز حساب Meta Developer + صفحة فيسبوك + حساب إنستغرام Business مربوط بها.
2. في ملف `.env` ضع `APP_MODE=live` واملأ مفاتيح Meta وخدمات الذكاء الاصطناعي والتخزين.
3. أكمل الأجزاء المعلّمة بـ `NotImplementedError` في `app/ai/*` و`app/storage.py` بربط المزوّد الفعلي.

> **للتشغيل المتواصل ٢٤/٧:** يُفضّل استضافته على خادم سحابي (VPS) بدل إبقاء حاسوبك مفتوحًا —
> أأمن وأثبت وأرخص. التفاصيل في وثيقة الخطة بالمجلد الرئيسي.

## بنية المشروع

```
social_automation/
├── run.bat                 # تشغيل ويندوز بضغطة
├── requirements.txt
├── .env.example            # قالب المفاتيح (فارغ)
├── app/
│   ├── main.py             # FastAPI + لوحة تحكم + نقاط API
│   ├── config.py           # الإعدادات ووضع mock/live
│   ├── database.py         # SQLAlchemy (SQLite افتراضيًا)
│   ├── models.py           # الجداول متعدّدة العلامات (brand_id)
│   ├── seed.py             # تهيئة بيج رايش + إنكيدو
│   ├── services.py         # التحليل + التوليد + الجدولة + النشر
│   ├── scheduler.py        # APScheduler (نشر كل دقيقة + تخطيط يومي)
│   ├── ai/                 # vision.py · text.py · image.py
│   ├── publishers/         # facebook.py · instagram.py
│   └── storage.py          # رفع الوسائط لتخزين عام
```

## نقاط الـ API

| الطريقة | المسار | الوظيفة |
|---------|--------|---------|
| `GET`  | `/` | لوحة التحكم |
| `GET`  | `/api/brands` | حالة كل علامة (البنك/المجدول/المنشور) |
| `POST` | `/api/sources` | إضافة مصدر (وصف/صورة) + تحليل + توليد |
| `POST` | `/api/brands/{slug}/plan` | تخطيط منشورات اليوم |
| `POST` | `/api/run-now` | نشر فوري لما حان وقته (اختبار) |
| `GET`  | `/api/posts?status=` | قائمة المنشورات |
